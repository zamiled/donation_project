# Pulse — Streamer Donation Demo

เว็บรับโดเนทส่วนตัวสำหรับสตรีมเมอร์หนึ่งคน ใช้ React + Vite และ Go REST API จำลองการส่งเงิน ไม่มีการรับเงินจริง

## เริ่มต้น

Go 1.24+ และ Node.js 20.19+ หรือ 22.12+ (แนะนำ Node 24)

```sh
cd backend
go run .
```

เปิด terminal อีกหน้าหนึ่ง:

```sh
cd frontend
npm ci
npm run dev
```

ใน cloud นี้เพิ่ม `/workspace/tools/go/bin` ใน PATH เพื่อใช้ Go ที่ติดตั้งไว้
Frontend พอร์ต 5173; Go พอร์ต 8080; Vite proxy ส่ง `/api` ไป backend

## หน้าเว็บ

- `/` หน้าโปรไฟล์สตรีมเมอร์ ฟอร์มจำนวนเงิน ชื่อ และข้อความ ส่งแล้วได้รับรายการยืนยัน
- `/dashboard` ดูยอดจำลองทั้งหมด เป้าหมาย และประวัติล่าสุด อัปเดตทุก 3 วินาที
- `/overlay` หน้าพื้นหลังโปร่งใสสำหรับ OBS Browser Source ขนาด 800 × 400

เปิด overlay ก่อนส่งโดเนท รายการใหม่จะแสดงตามลำดับครั้งละ 7 วินาที โดยตรวจรายการทุก 1 วินาทีและเริ่มแสดงภายในประมาณ 8 วินาที รายการเก่าตอนเปิดหน้าจะไม่ถูกเล่นซ้ำ การดึงข้อมูลจำกัด 20 รายการล่าสุด จึงเหมาะสำหรับ demo ที่มีรายการไม่ถี่มาก ยังไม่ได้ทดสอบในโปรแกรม OBS จริง

โปรไฟล์ตัวอย่างชื่อ `YOUR STREAM` และเป้าหมายอัปเกรดไมค์ 10,000 บาท อยู่ใน `/api/profile` ของ `backend/main.go` สามารถแก้ให้เป็นข้อมูลของคุณได้

รายการบันทึกใน `backend/data/streamer-donations.json` ซึ่งถูก ignore จาก Git แยกจากข้อมูลตัวอย่างโครงการเดิม ค่า `ADDR` เปลี่ยนที่อยู่ backend และ `DONATION_DATA_FILE` เปลี่ยนตำแหน่งข้อมูลได้

## API

| Method | Path | ผลลัพธ์ |
| --- | --- | --- |
| GET | `/api/health` | สถานะและโหมด demo |
| GET | `/api/profile` | โปรไฟล์ เป้าหมาย ยอด และจำนวนรายการ |
| GET | `/api/donations` | 20 รายการล่าสุด เรียงใหม่ก่อน |
| POST | `/api/donations` | สร้างรายการด้วย `amount`, `name`, `message` |

ยอดจำนวนเต็ม 1–1,000,000 บาท ชื่อไม่เกิน 80 และข้อความไม่เกิน 300 ตัวอักษร ชื่อและข้อความเป็นข้อมูลสาธารณะใน demo ไม่ควรกรอกข้อมูลส่วนตัวจริง

## ขอบเขต

ยังไม่มี login, ระบบชำระเงินจริง, TTS, moderation หรือฐานข้อมูล production แดชบอร์ดเข้าถึงได้โดยไม่ต้องยืนยันตัวตน ใช้ทดลองในเครื่องก่อน ระบบ JSON รองรับ backend หนึ่ง process ฟอนต์ใช้ Google Fonts พร้อม sans-serif fallback
